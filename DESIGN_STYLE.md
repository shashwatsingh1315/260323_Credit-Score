# High-End Design Style

## Overview
Aura is standardizing the application into a premium, unified aesthetic inspired by top-tier modern interfaces. The design leans into dark mode elegance, continuous radii (squircles), purposeful whitespace, and precise, tokenized styling.

## Tokens

### Colors
All colors follow semantic HSL tokens to ensure pristine dark mode compatibility.
- `background`: Application background.
- `foreground`: Primary text color.
- `muted`: Subdued backgrounds (e.g., previously bg-tertiary).
- `muted-foreground`: Subdued text (e.g., previously text-muted/secondary).
- `card`: Elevated surface backgrounds.
- `border`: Subtle borders and dividers.
- `primary`: Key actions and active states.

### Typography
- Maintained crisp `Inter` font scale.
- Emphasized hierarchical text contrast.

### Spacing & Radii
- Spacing strictly follows the Tailwind 4px/8px base rhythm.
- Radii are unified using `--radius` variable.
