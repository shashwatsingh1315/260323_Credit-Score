## 2025-05-01 - [CSS Module Legacy Variable Migration] **Learning:** The legacy codebase heavily relied on CSS Custom properties mapping to raw hex values (`--bg-primary`, `--text-secondary`, etc.) which fundamentally breaks design token logic for dark mode / color scalability. Additionally, semi-transparent states were configured via hardcoded `rgba()` values which ignore theming completely. **Action:** Refactored all CSS Modules to utilize the HSL token variable stack (e.g. `hsl(var(--background))`) and adopted `hsla()` with alpha division syntax (e.g. `hsla(var(--foreground) / 0.05)`) for semi-transparent layers. Updated `tailwind.config.js` ESLint error handling for node `require`.
