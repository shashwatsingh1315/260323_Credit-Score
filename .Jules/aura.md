## 2024-05-24 - Semantic Token Refactor
**Learning:** The application is heavily reliant on legacy CSS variables (e.g. `var(--bg-primary)`, `var(--border-color)`, `var(--text-primary)`) defined in `globals.css` which are essentially hardcoded colors rather than semantic standard Tailwind tokens. There is a need to move to standard HSL variable based Tailwind usage (`hsl(var(--background))`, `hsl(var(--foreground))`) for better theming support and to adhere to modern design system principles. The current codebase has many direct hex color replacements or non-standard token usage which conflicts with high-end aesthetic directives.
**Action:** Update all css modules and inline usages from legacy custom properties to standard semantic Tailwind CSS tokens. Remove these legacy variable definitions from `globals.css` once they are safely migrated across all components. Implement missing semantic tokens into `tailwind.config.js` and document them in `DESIGN_STYLE.md`.
## 2024-05-24 - Typography Tokens
**Learning:** Found multiple instances of hardcoded tiny text values (`text-[10px]`, `text-[11px]`) used across tables and small pills. These need standard token representation in tailwind config.
**Action:** The tailwind config already has `text-tiny` which is `10px`. Adding `text-micro` for `11px` in `tailwind.config.js` and using standard tailwind classes instead of arbitrary bracket notation.
