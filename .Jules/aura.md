## 2024-05-18 - [Tokenizing Typography] **Learning:** Found extensive use of arbitrary text sizes `text-[10px]` and `text-[11px]` representing small, capitalized, tracker or pill text that violates the system typography scale. The tailwind configuration defines `text-tiny` for exactly this purpose. **Action:** Refactor all `text-[10px]` and `text-[11px]` to use `text-tiny` across the application to ensure structural uniformity and scalability.
