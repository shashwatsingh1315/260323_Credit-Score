## 2024-04-13 - Legacy HEX CSS Variable Conflict **Learning:** Legacy hardcoded hex CSS variables (e.g., `--bg-primary`, `--text-primary`) prevent proper dark mode support and conflict with the semantic token scale mapping. We also require `<alpha-value>` syntax in Tailwind config for opacity modifiers to work correctly with CSS variables. **Action:** Strip legacy hex variables from globals.css, update tailwind.config.js to use `/<alpha-value>`, and update all CSS modules to map to the new semantic tokens using `hsl(var(--token))`.
