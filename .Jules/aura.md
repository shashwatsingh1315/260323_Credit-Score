## 2025-06-15 - Initial Audit **Learning:** Numerous components (e.g. CollectionsClient, NewCaseForm, various UI components) use arbitrary pixel values like `text-[10px]`, `text-[11px]`, `w-[200px]`, `max-h-[400px]` and legacy hex colors instead of standard Tailwind tokens (base-4 scale, semantic colors). **Action:** We must establish a strict `DESIGN_STYLE.md` as our source of truth and systematically replace these hardcoded pixel arrays with Tailwind standard utilities (e.g. `text-xs`, `w-48`, `max-h-96`, semantic colors).
