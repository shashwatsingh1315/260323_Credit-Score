## 2026-06-30 - [CSS Token Migration] **Learning:** The application extensively uses legacy hex-based CSS custom properties (`--bg-primary`, `--text-primary`, `--border-color`) which conflict with the established standard of Tailwind HSL tokens. This causes scalability issues for dark mode and color unification. **Action:** Refactored CSS modules to strictly use Tailwind HSL variables (e.g., `hsl(var(--background))`, `hsl(var(--foreground))`) ensuring consistency with the global token config.
