## 2024-05-18 - Replacing legacy CSS hex variables with HSL token references **Learning:** The codebase has legacy hex-based CSS variables like --bg-primary, --text-primary, --border-color that conflict with the Tailwind HSL token variables like --background, --foreground, --border. We lack adherence to standard CSS variables. **Action:** Replace legacy hex-based CSS variables with standard Tailwind HSL references in global and module css.
