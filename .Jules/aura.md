## 2024-05-24 - [Initial Review] **Learning:** Identified extensive use of legacy CSS modules containing hardcoded `--bg-primary` style variables and custom classes like `.btn-primary` alongside tailwind utility classes. **Action:** Refactor UI elements to use modern Tailwind HSL token variables (e.g. `bg-background` and `text-foreground`). ## 2024-05-24 - [Typography Token Migration] **Learning:** Found extensive use of arbitrary typography values (e.g. `text-[10px]`, `text-[11px]`) across multiple components. The tailwind config already defines a custom `text-tiny` (`["10px", "14px"]`) token. **Action:** We need to add `text-micro` (`["11px", "16px"]`) to `tailwind.config.js` and strictly replace all bracket-notation font sizes with these standard tokens to ensure uniformity.
