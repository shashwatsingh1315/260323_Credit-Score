## 2025-02-18 - Shell Module CSS Legacy Token Cleanup\n\n**Learning:** The `Shell.module.css` file contains significant legacy styling utilizing hardcoded pixel values (e.g., `width: 260px`, `height: 70px`), arbitrary hex colors (via old `--bg-primary`, `--text-primary` tokens that were re-mapped but should be replaced entirely with Tailwind utility classes/modern `hsl()` tokens), and custom hover states that duplicate standard UI component behavior. This conflicts with the project's strategy to move towards Tailwind utility classes and native design tokens for Layout and Component structure, causing duplicated logic and preventing unified scaling in the main `Shell.tsx`.\n\n**Action:** Refactor `Shell.tsx` to completely drop the `Shell.module.css` import, translating all structural layout (flexbox, grid, specific spacing), typography, and color tokens into Tailwind utility classes using the standardized base-4/base-8 spacing, fractional sizing tokens, and semantic color tokens (e.g., `bg-background`, `text-foreground`, `border-border`). Delete `Shell.module.css` post-refactor.
