## 2025-04-09 - [White-on-White Input Bug] **Learning:** Legacy variables (--bg-tertiary, --text-primary) used for forms cause white-on-white text rendering in dark mode because they do not correctly adopt inverse values or semantic color variables. **Action:** Apply standard semantic variables (hsl(var(--background)), hsl(var(--foreground))) mapped to CSS variables to all global form elements to prevent missing context and ensure correct behavior.
